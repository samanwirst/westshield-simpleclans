# WestShield rebranding

Player-facing server names, commands, plugin identities, map IDs, domains and documentation use WestShield. Existing worlds keep their original private storage identifiers and UUIDs, and inventory/claim/clan records keep their existing relationships. They are not regenerated or reset by rebranding.

The territory plugin accepts the previous namespaced selection-wand key as a read-only compatibility alias. Newly issued tools use its WestShield namespace.

Earlier verification receipts are preserved unchanged under `docs/history/pre-westshield`; they describe the versions recorded inside them, not this release. Existing Git commits and old backup archives remain historical records.
